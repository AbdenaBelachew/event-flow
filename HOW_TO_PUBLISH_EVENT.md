# How to Publish Your Event - Step by Step

## 📍 Where to Find the Publish Button

There are **2 places** where you can publish your event:

---

## Option 1: From Event Detail Page (Recommended)

### Steps:
1. **Go to Dashboard** (after login)
2. **Find your event** in the list
3. **Click the event name** to open event details
4. **Look at the right sidebar** labeled "Admin Actions"
5. **Click the green button** that says "🚀 Publish Event"

### Visual Path:
```
Dashboard 
  ↓
[Your Event Card]
  ↓
Event Detail Page
  ↓
Right Sidebar → "Admin Actions" section
  ↓
Green "🚀 Publish Event" Button ← CLICK HERE
```

### When Does This Button Appear?
- ✅ Only shows if event status is **"draft"** (not yet published)
- ✅ Only shows if you're the **event owner** (company that created it)
- ❌ Disappears once the event is **already published**

---

## Option 2: From Event Edit Page

### Steps:
1. **Go to Dashboard**
2. **Click your event name** 
3. **Click the "Edit Event" button** (top of page)
4. **Look at the bottom** of the form
5. **Click the green button** that says "Publish Event"

### Visual Path:
```
Event Detail Page
  ↓
Top Right → "Edit Event" button
  ↓
Edit Page Opens
  ↓
Scroll to bottom of form
  ↓
Green "Publish Event" button ← CLICK HERE
```

### When Does This Button Appear?
- ✅ Only shows on Edit page if status is **"draft"**
- ✅ Appears next to "Save Changes" button
- ❌ Disappears after you publish

---

## 📋 Complete Workflow to Publish

### 1. Create Event ✅
```
Dashboard → "Create Event" button
  ↓
Fill in:
  - Title
  - Description
  - Venue (location)
  - City
  - Event dates
  - Upload image
  ↓
Click "Create Event"
Status: DRAFT (not visible to public yet)
```

### 2. Add Ticket Types ✅
```
Event Detail Page
  ↓
Click "Edit Event"
  ↓
Go to "Ticket Types" tab
  ↓
Add tickets:
  - Name (e.g., "VIP", "General")
  - Price (e.g., 500 ETB)
  - Quantity (e.g., 100 tickets)
  ↓
Click "Add Ticket Type"
```

### 3. Publish Event 🚀
```
Option A: From Detail Page
  ↓
Right sidebar → Green "Publish Event" button

OR Option B: From Edit Page
  ↓
Bottom of form → Green "Publish Event" button
  ↓
Click it
```

### 4. Confirm Published ✅
```
Event status changes to: "published"
Event now appears in "Browse Events"
Customers can see and buy tickets
```

## 🎯 Quick Checklist Before Publishing

Before you click "Publish Event", make sure:

- [ ] Event title is filled in
- [ ] Event dates are set (start and end)
- [ ] Venue/location is entered
- [ ] City is selected
- [ ] At least 1 ticket type is added
- [ ] Ticket types have:
  - [ ] Name (e.g., "VIP")
  - [ ] Price in ETB (e.g., 500)
  - [ ] Quantity available (e.g., 100)
- [ ] Event image is uploaded (optional but recommended)

## 🔴 Common Issues & Solutions

### Issue: "Publish Event" Button Not Appearing

**Reason 1: Event Already Published**
- Look for status badge on page
- If it says "published" in green, it's already public
- To make changes, click "Edit Event"

**Reason 2: Not the Event Owner**
- Only the company that created the event can publish it
- Check if logged in with correct account

**Reason 3: Missing Required Fields**
- Event must have all basic details
- Must have at least 1 ticket type
- Try editing event to complete missing fields

### Issue: Button Doesn't Work After Clicking

**Solution 1: Wait a moment**
- Publishing takes a few seconds
- Watch the page for status change

**Solution 2: Check browser console**
- Press F12 to open Developer Tools
- Look for error messages
- Check Network tab for API errors

**Solution 3: Refresh page**
- Press F5 to refresh
- Try clicking publish again

### Issue: Event Published but Not Showing in Browse

**Reason 1: Page not refreshed**
- Click "Browse Events"
- If still not there, refresh page (F5)

**Reason 2: Event dates in past**
- Event dates must be in the future
- Check event dates are after today

**Reason 3: No ticket types available**
- Event must have at least 1 ticket type
- Go back and add ticket types

## 📊 After Publishing

### What Changes When You Publish?

| Feature | Before Publish | After Publish |
|---------|---|---|
| **Visibility** | Dashboard only | Public + Dashboard |
| **Browse Events** | ❌ Not visible | ✅ Visible |
| **Status Badge** | Yellow "draft" | Green "published" |
| **Customer Access** | ❌ Cannot see | ✅ Can view & buy |
| **Edit Access** | ✅ Can edit | ✅ Can still edit |
| **Publish Button** | ✅ Visible | ❌ Disappears |

### Can You Unpublish?

Currently **NO** - once published, event stays public. If needed:
- You can edit event details
- You can cancel the event (sets status to "cancelled")
- Customers won't be able to buy more tickets
