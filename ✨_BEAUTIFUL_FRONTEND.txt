🚀 HOW TO USE THE IMAGE UPLOAD
───────────────────────────────────────────────────────────────────────────────

STEP 1: Go to Create Event
  • Click "Create Event" button on dashboard
  • Or navigate to /events/create

STEP 2: Fill Event Details
  • Enter event title
  • Write description
  • Add venue & city
  • Set dates & times
  • Configure sales window

STEP 3: Upload Image (Right Sidebar)
  • See "Cover Image" section
  • Click upload area
  • File picker opens
  • Select image from computer
  • See preview instantly

STEP 4: Manage Image
  • View preview
  • See file name
  • Click "Change Image" to swap
  • Click trash icon to remove
  • Get success message

STEP 5: Create Event
  • Click "Create Event" button
  • Image stored with event
  • Event created successfully
  • Redirected to edit page

───────────────────────────────────────────────────────────────────────────────
💡 PRO TIPS
───────────────────────────────────────────────────────────────────────────────

IMAGES:
  • Use high-quality images (minimum 500x300px)
  • Aspect ratio ~16:9 works best
  • Clear, bright images stand out
  • Avoid text on images
  • PNG or JPG recommended

COLORS:
  • Match your brand colors
  • Avoid cluttered images
  • Use professional photos
  • Ensure good contrast
  • Test on mobile view

FORMATTING:
  • Max file size: 5MB
  • Supported: PNG, JPG, GIF
  • Large files may be slow
  • Optimize before upload
  • Use compression tools
